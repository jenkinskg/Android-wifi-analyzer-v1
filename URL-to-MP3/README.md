URL to MP3 Android app. Paste an authorized supported link, select MP3 quality, convert, then play or share. Audio is saved in Music/URL to MP3. No Termux. Android 10+.
Open URL-to-MP3 in Android Studio or run GitHub Actions on the url-to-mp3-app branch. Uses GPL-3.0 yt-dlp Android library: https://github.com/yausername/youtubedl-android .
